# MKLIO CINEMA — GitHub Pages Edition

A static cinema discovery catalogue with Google Drive Embed playback for videos the administrator owns or is authorised to share.

- Existing green-and-white design retained.
- Google Drive Embed Player retained.
- Firebase Authentication + Firestore metadata only.
- No Cloudinary and no Firebase Storage.
- SEO: canonical metadata, Open Graph, Twitter cards, JSON-LD, sitemap, robots.txt, favicon and shareable movie pages.
- Catalogue entries: licensed movies, official trailers, behind-the-scenes videos and written reviews.
- Public information pages: About, Contact, Privacy, Terms and Copyright.

Extract this ZIP and upload its contents to the GitHub repository root. Follow `SETUP-TA.md` before publishing.
