# MKLIO CINEMA

GitHub Pages-ready static cinema catalogue. Admin adds Google Drive share links; visitors browse by actor and watch through Google Drive Embed Player.

- No Cloudinary integration.
- No Firebase Storage integration.
- Firebase Authentication protects the Admin interface.
- Firebase Firestore stores video metadata, likes and comments only.

See [SETUP-TA.md](SETUP-TA.md) for Tamil setup instructions.
